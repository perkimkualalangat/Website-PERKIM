Status data

Peta ini berfungsi sebagai komponen draf. Sumber tunggal ialah data/database_lokasi_perkim.md. Selepas menyuntingnya, jalankan python tools/bina_lokasi.py semak dan python tools/bina_lokasi.py bina untuk menjana data/perkim-network.json. Jangan sunting fail JSON itu secara manual.

Untuk laman awam, gunakan bina --awam supaya hanya rekod berstatus disahkan dipaparkan. Halaman mesti dibuka melalui pelayan tempatan (start.bat) atau hos statik, kerana data dimuat melalui fetch.
